| Path | Description |
|------|-------------|
| `.claude/CLAUDE.md` | Project context loaded automatically by Claude Code |
| `.claude/docs/` | Software Requirements Specification (original PDF and text copy) |
| `.github/CODEOWNERS` | Code owners requested as reviewers on every PR |
| `.github/pull_request_template.md` | Default description for new pull requests |
| `src/Main.java` | Application entry point |
| `src/world_render/` | World rendering |
| `src/world_render/graphics_engine/` | Graphics engine rendering |
| `src/world_render/obstacles/` | Obstacle rendering |
| `src/world_render/weather/` | Weather rendering and simulation |
| `src/drone/` | Drone logic |
| `src/drone/physics/` | Drone physics |
| `test/` | JUnit 5 tests, mirroring the `src/` package layout |
